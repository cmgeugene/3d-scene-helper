## 완료한 목표

저장된 `OutputCamera`와 현재 Three.js scene을 사용해 editor canvas screenshot이 아닌 offscreen `WebGLRenderTarget`에서 exact-resolution PNG를 생성한다. 1280×720, 1920×1080, 1080×1920, 1080×1080 square, 1920×804 cinematic preset과 각 축 64..4096 custom dimensions를 제공한다.

Custom dimensions는 width-driven 또는 height-driven nearest-integer aspect lock 결과만 허용하며 임의의 1px mismatch를 import/schema/export 경계에서 거부한다. 고정 cinematic preset 1920×804만 명시적인 canonical exception이다.

Clean export는 layer 0만, reference export는 layer 0+2와 percentage composition guides를 포함한다. layer 1의 grid, axes, camera/selection/transform helpers는 두 mode 모두에서 제외한다. ExportDialog는 filename, aspect, preset/custom dimensions, active lock, clean/reference, busy/error 상태를 제공하고 sanitized filename으로 실제 browser download를 실행한다.

## 구현한 계약

### Output model과 aspect validation

- Preset은 HD 1280×720, Full HD 1920×1080, portrait 1080×1920, square 1080×1080, cinematic 1920×804다.
- Width/height는 integer 64..4096이어야 한다.
- Width edit은 height를, height edit은 width를 active aspect의 nearest integer로 계산한다.
- Shared `isAspectLockedOutputSize`가 schema/import와 export validation의 단일 판정 경계다.
- Width-driven 또는 height-driven rounding 결과를 허용한다. 예를 들어 16:9 113×64와 9:16 64×113, 9:16 height 1000에서 563×1000을 허용한다.
- 1:1 100×99, 16:9 1280×719, 9:16 1080×1919 같은 임의의 1px mismatch는 거부한다.
- Fixed cinematic 1920×804는 canonical preset exception으로 허용한다.
- Filename은 path/control/unsafe punctuation을 제거하고 `.png` suffix를 정확히 하나 붙이며 비어 있으면 `scene.png`를 사용한다.

### Offscreen renderer와 deterministic cleanup

- Saved output camera position, target, focal length, roll과 output aspect로 별도 `PerspectiveCamera`를 재구성한다.
- `WebGLRenderTarget`은 RGBA unsigned-byte, depth enabled, no stencil/MSAA로 target resolution에 생성한다.
- Export 동안 renderer pixel ratio를 1로 고정하고 target viewport/scissor를 exact dimensions로 설정한다.
- `readRenderTargetPixels`의 bottom-up rows를 in-place row swap으로 수직 반전해 불필요한 full RGBA copy 하나를 제거한다.
- 임시 2D canvas는 flipped pixels와 reference guides를 PNG blob으로 encode하는 데만 사용한다. Live editor canvas의 screenshot 또는 `toDataURL`을 primary source로 사용하지 않는다.
- Render target 생성 직후의 texture setup, pixel allocation, renderer-state capture도 outer `try/finally` 안에 있으며 모든 success/failure path에서 target을 dispose한다.
- Render/readback 중에는 target, pixel ratio, viewport, scissor, scissor-test, output color space, exposure를 복원한다.
- Temporary canvas는 success/error 모두 backing dimensions를 0으로 만들고 DOM에서 제거한다.
- Export 전·readback 후 WebGL context loss를 검사하고, target dimensions를 GPU `MAX_TEXTURE_SIZE`와 `MAX_RENDERBUFFER_SIZE`에 대조한다. 실패는 성공한 black PNG로 오인하지 않고 dialog error로 반환한다.

### Layer와 reference policy

- Clean camera mask는 layer 0만 포함한다.
- Reference camera mask는 layer 0+2를 포함한다.
- Layer 1은 어떤 mode에도 포함하지 않는다.
- Clean은 thirds, center, action-safe, title-safe를 모두 숨긴다.
- Reference는 활성 thirds/center 및 5%/10% safe-area flags를 target pixel dimensions의 percentage 위치에 그린다.
- Existing motion guide metadata/flag는 S10 범위이므로 reference PNG에 추가하지 않았다.

### Dialog, lifecycle, download

- Dialog는 filename, aspect, resolution, custom width/height, aspect-lock indicator, clean/reference radio, result summary를 제공한다.
- Initial focus는 filename이며 Tab focus trap, Escape/cancel, opener focus return을 제공한다.
- Dialog 내부 keydown propagation을 차단해 Delete/Backspace/W/E/R 등 global editor shortcuts가 scene을 변경하지 못한다.
- Preparing/exporting 동안 controls와 duplicate submit을 막고 오류 시 dialog와 live document를 보존해 재시도할 수 있다.
- Capture와 PNG encoding이 성공한 뒤에만 document output을 commit하고 real anchor download를 실행한다.
- Object URL은 deferred cleanup하고 temporary anchor를 제거한다.
- `SceneViewport`의 live R3F renderer/scene을 handler로 연결하되 runtime objects를 serializable store에 저장하지 않는다.
- R3F bridge rerender가 deprecated soft-shadow setting을 다시 적용하지 않도록 Canvas shadow type을 explicit `percentage`(PCF)로 고정했다.
