## 완료한 목표

S02에서 정의한 inferred `SceneDocument`와 Zustand `editorStore`를 재정의하지 않고 React editor shell에 연결했다. 편집기는 상단 toolbar, 에셋/아웃라이너, 중앙 viewport placeholder, inspector, status bar로 구성되며 1280×720 이상의 데스크톱에서 3열로 표시된다.

새 장면과 기본 장면 초기화, 화면비와 가이드, 아웃라이너 선택, inspector panel state가 기존 store action과 동기화된다. 저장·불러오기·JSON·PNG controls와 오브젝트 추가 controls는 후속 세션 범위를 표시하는 disabled shell로만 제공한다.

실제 R3F Canvas, Three.js object/scene rendering, 오브젝트 추가, transform 편집, persistence, export 및 undo/redo는 구현하지 않았다.

## 구현한 계약

### Editor shell과 desktop layout

- `<header>`, `<main>`, 두 `<aside>`, labelled `<section>`, `<footer>`를 사용한 semantic shell.
- 240px 에셋/아웃라이너, 가변 viewport, 280px inspector의 3열 workspace.
- 중앙에는 S04 전용 실제 Canvas 대신 한국어 starter-scene placeholder와 기존 WebGL 상태만 표시.
- 1280px 미만에서는 editor를 숨기고 `이 편집기는 1280×720 이상의 데스크톱 화면이 필요합니다.` 안내를 표시.
- 모든 enabled button/select/tab과 아웃라이너 행에 공통 `:focus-visible` outline 적용.

### Toolbar와 store 연결

- `새 장면`과 `기본 장면으로 초기화`가 기존 `resetScene()`을 호출.
- `16:9`, `9:16`, `1:1`, `2.39:1` preset 선택이 기존 `setOutput()`을 통해 aspect와 default dimensions를 함께 갱신.
- thirds, center, action safe, title safe checkbox와 `모든 가이드 숨기기`가 기존 `setGuideVisibility()`를 사용. 모두 숨기기는 motion guide도 false로 정리.
- 로컬 저장, 최근 장면 열기, JSON 가져오기/내보내기, PNG 내보내기는 S08/S09 구현 전 disabled control로 노출.
- undo/redo placeholder는 만들지 않음.

### Outliner, Inspector, StatusBar

- `document.objects`를 list로 표시하고 행 클릭이 기존 `selectObject(id)`를 호출.
- `aria-pressed`로 선택 상태를 색 외에도 전달.
- Inspector 장면 panel에 위치·회전·크기 X/Y/Z number inputs를 렌더하고 선택이 없으면 disabled. 실제 numeric commit은 S05 범위이므로 read-only 표시만 제공.
- 장면/카메라/조명/출력 tablist가 기존 `activePanel`과 `setActivePanel()`에 연결됨. 후속 panel은 해당 세션에서 제공된다는 한국어 안내만 표시.
- StatusBar가 선택, transform mode, 화면비를 `aria-live="polite"`로 알림.

## 결정과 범위 준수

- `SceneDocument`, `EditorStore`, guide/output/panel types를 새로 정의하지 않고 S02 exports만 import했다.
- React components는 주입된 vanilla Zustand store를 `useStore(store, selector)`로 구독한다.
- module-level App store 한 개를 생성해 panel 간 동일한 상태 source를 공유하며 별도 UI state 계층을 만들지 않았다.
- numeric transform commit은 S05, object add와 Canvas는 S04, camera/lighting runtime은 S06/S07, persistence/history는 S08, clean PNG는 S09로 미뤘다.
- disabled future controls에는 제공 세션을 알리는 한국어 title을 부여했다.
- active panel tabs는 panel-state behavior만 제공하고 후속 도메인 설정을 선행 구현하지 않는다.

## 알려진 제한

- viewport는 실제 R3F Canvas가 아닌 placeholder다.
- 에셋 추가와 저장/불러오기/JSON/PNG controls는 의도적으로 disabled다.
- Inspector number inputs는 선택된 transform 값을 표시하지만 S05 전에는 read-only다.
- 카메라·조명·출력 panels는 activePanel 전환과 안내만 제공한다.
- undo/redo는 S08까지 DOM에 존재하지 않는다.
