## 구현한 계약

### SceneDocument와 schema

- `version: 1` strict Zod schema 및 `z.infer` 기반 `SceneDocument`.
- stable document/object ID와 object ID 중복 거부.
- plain-data position, degree rotation, strictly positive scale 및 dimensions.
- 실제 exportable floor와 cube, sphere, cylinder, plane, mannequin object kinds.
- object name, color, visibility, exportability.
- document-owned OutputCamera의 position, target, focal length, roll.
- environment/key/fill/rim, exposure, shadow policy를 포함한 직렬화 lighting과 background.
- aspect ratio, exact integer dimensions, clean/reference mode를 포함한 output.
- active aspect와 output dimensions가 1px 이내에서 일치하도록 검증. 이 허용 오차는 명세의 `1920×804` cinematic preset을 수용한다.
- optional subject/camera motion metadata와 기존 object 참조 검증.
- 최대 2,000자 scene notes.
- unknown/runtime field, unsupported version, malformed colors/sizes/IDs 거부.

### Constants와 presets

- film gauge `36mm`, mannequin reference height `1.7m`.
- render layers scene/editor/reference = `0/1/2`.
- action/title safe inset = `5%/10%`.
- namespaced scene storage key와 output range/shadow map constants.
- aspect presets: `16:9`, `9:16`, `1:1`, `2.39:1`.
- lens presets: `18/24/35/50/85mm`.
- bounds-derived metadata only인 six camera shot presets.
- neutral studio, daylight, sunset, night, cinematic backlight lighting presets.

### Store와 mutation 경계

- document와 transient editor state를 별도 store fields로 유지.
- add/select/hover/rename/color/visibility/duplicate/delete/reset actions.
- camera, lighting/background, output, motion metadata 및 notes document mutations.
- `beginTransform()`은 selected object의 시작 transform을 transient state에 복사하고 문서나 dirty 상태를 쓰지 않는다.
- `commitTransform(finalTransform)`에서만 validated document transform을 한 번 확정한다.
- 향후 S08 history용 document mutation allowlist를 고정하고 selection/hover/panel/navigation/export progress를 제외했다.
- missing object ID는 dangling selection/hover나 false dirty를 만들지 않는 no-op/null 정책으로 통일했다.
- delete/reset에서 selection, hover, in-progress transform 및 관련 subject motion guide를 정리한다.
- caller-owned navigation/export 입력은 clone해 aliasing을 방지한다.

## 결정과 범위 준수

- `SceneDocument`는 `sceneSchema.ts`에서만 정의하며 별도 interface를 만들지 않았다.
- `types.ts`의 vector/transform alias도 inferred `SceneDocument`/`SceneObject`에서 파생한다.
- store에 Three.js, R3F, DOM, Canvas, renderer, camera instance 또는 runtime resource를 넣지 않았다.
- camera shot presets는 subject bounds로 후속 계산할 serializable framing metadata만 정의했고 실제 camera math는 S06으로 미뤘다.
- history stack은 S08 범위이므로 mutation allowlist와 commit boundary만 고정했다.
- output aspect의 1px tolerance는 exact integer rounding 및 명세의 cinematic `1920×804`를 위한 schema boundary다. custom dimension recalculation UI/logic은 S09다.

## 알려진 제한

- editor store는 아직 React UI와 연결되지 않았다.
- undo/redo와 history entries는 구현하지 않았고 S08에서 allowlist를 소비한다.
- localStorage, JSON codec/import/export 및 migration은 S08 범위다.
- 실제 Three.js/R3F object mapping, bounds, camera calculations, lighting mapping은 후속 세션 범위다.
- output validation은 schema 불변식만 제공하며 custom dimension UX는 S09에서 구현한다.
- invalid/colliding injected object ID의 atomic failure를 명시적으로 고정하는 전용 store test는 non-blocking review suggestion으로 남아 있다.
