# S17 — Resizable Scene Assistant dock

## 결과

작은 고정 폭이던 우측 속성·Scene Assistant 영역을 사용자가 조절할 수 있는 도크로 변경했다.

- 기본 폭 `420px`, 최소 `320px`, 최대 `720px` 및 화면 너비의 `45%`
- 마우스 드래그와 키보드 좌우 화살표 리사이즈
- `넓게`와 `이전 너비` 전환
- 전체 우측 도크 접기·펼치기
- 마지막 폭과 접힘 상태를 localStorage에 저장
- Scene Assistant의 `대화 / 변환 계약` 탭 분리
- 긴 변환 계약 상세를 기본 접힘으로 변경
- 대화 입력창을 패널 하단에 고정
- `Enter` 전송과 `Shift+Enter` 줄바꿈

## 수동 확인

1. 앱을 열고 우측 패널 왼쪽 경계선을 좌우로 드래그한다.
2. `넓게`를 눌러 최대 폭으로 바뀌는지 확인하고 `이전 너비`로 복귀한다.
3. `접기`를 누른 뒤 세로 Assistant 레일의 펼치기 버튼으로 복원한다.
4. 폭을 바꾸거나 패널을 접은 상태에서 새로고침해 상태가 유지되는지 확인한다.
5. Companion 연결 후 `대화`와 `변환 계약` 탭을 전환한다.
6. 변환 계약 상세가 처음에는 접혀 있고 클릭하면 기존 계약 내용이 보이는지 확인한다.
7. 대화가 길어져도 입력창이 아래쪽에 남는지 확인한다.
8. `Shift+Enter`는 줄바꿈, `Enter`는 전송인지 확인한다.
