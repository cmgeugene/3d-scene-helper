## 완료한 목표

편집기 document mutation에 50-entry undo/redo history를 연결하고 selection, hover, panel, transient navigation 및 render/export 상태를 history에서 제외했다. S05 `beginTransform`/`commitTransform` 경계를 사용해 연속 gizmo drag 하나를 history entry 하나로 기록한다. toolbar와 input-focus guard가 있는 `Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z` shortcut을 제공한다.

기존 versioned Zod `SceneDocument` schema를 재사용하는 JSON codec과 migration placeholder를 추가했다. unknown version, malformed JSON, schema-invalid payload 및 약 4 MiB를 넘는 scene을 명시적으로 거부한다. versioned namespaced localStorage key와 500 ms debounced autosave를 사용하며 quota/storage failure를 사용자에게 실행 가능한 메시지로 표시한다.

앱은 valid autosave를 시작 시 복원하고 malformed autosave를 파괴하지 않은 채 starter scene으로 안전하게 시작한다. dirty document만 `beforeunload`를 차단하고, 저장에 성공한 정확한 snapshot만 clean으로 표시한다. stale debounce completion과 cross-tab last-writer-wins를 차단한다.

Toolbar는 로컬 저장/열기, validated JSON import와 JSON download를 제공한다. malformed import, oversized import, dirty replacement 취소 및 늦게 완료된 stale import가 live document나 valid autosave를 파괴하지 않는다. S09 PNG export는 구현하지 않았다.

## 구현한 계약

### Document history

- `HISTORY_LIMIT = 50`인 bounded past/future stack을 사용한다.
- `DOCUMENT_MUTATION_KINDS` allowlist에 있는 object, transform, camera, lighting/background, output 및 motion metadata mutation만 기록한다.
- 새 document mutation은 redo stack을 무효화한다.
- history snapshot은 `structuredClone`으로 caller mutation과 격리한다.
- selection, hover, panel, transform mode, guide visibility, transient navigation 및 export state는 history에서 제외한다.
- undo가 object를 제거하면 그 object를 가리키던 selection/hover만 정리하고 여전히 valid한 transient state는 보존한다.
- camera history undo/redo만 document output camera와 runtime navigation을 동기화한다. 일반 document undo는 transient navigation을 보존한다.
- `beginTransform`에서 drag 시작 snapshot을 잡고 `commitTransform`에서만 history를 기록하므로 drag 하나가 entry 하나다.
- no-op object mutation은 history나 dirty 상태를 만들지 않는다. 기존 S07 explicit camera commit 계약은 유지하되 content가 동일하면 history/dirty는 만들지 않는다.
- persisted snapshot과 현재 document를 content 비교하여 undo/reset으로 persisted 내용에 복귀하면 즉시 clean이 된다.

### Toolbar와 keyboard

- undo/redo button은 `canUndo`/`canRedo`에 따라 disabled 상태를 반영한다.
- `Cmd/Ctrl+Z`와 `Cmd/Ctrl+Shift+Z`를 제공한다.
- input, textarea, select 및 contenteditable target에 focus가 있으면 scene history shortcut을 실행하지 않는다.
- history controls를 별도 toolbar grid row group에 배치해 1280 px 최소 지원 너비에서 horizontal overflow가 발생하지 않는다.

### Scene codec과 validation

- `sceneDocumentSchema`를 encode, parse, import 및 restore의 단일 validation source로 재사용한다.
- encode/parse result는 caller-side mutation과 격리된다.
- schema parse 전에 version을 확인하고 unknown version은 `UnsupportedSceneVersionError`로 거부한다.
- 현재 migration은 명시적인 placeholder boundary만 두며 speculative migration을 구현하지 않는다.
- malformed JSON과 current-version schema violation은 actionable `SceneCodecError`로 변환한다.
- `TextEncoder` UTF-8 serialized byte length 기준 약 4 MiB를 넘는 payload는 JSON parse 및 localStorage write 전에 거부한다.

### Local persistence와 dirty lifecycle

- storage key는 `i2v-3d-scene-helper:scene:v1`이다.
- autosave debounce는 500 ms다.
- 시작 시 valid autosave를 복원하고 history/transient state를 초기화한다.
- malformed autosave는 삭제하거나 덮어쓰지 않고 starter scene과 복원 오류 메시지를 제공한다.
- autosave 성공 시 저장한 정확한 document reference가 여전히 current일 때만 dirty를 해제한다.
- persisted replacement는 pending stale autosave timer를 취소한다.
- quota failure는 기존 valid autosave를 보존하고 JSON backup을 제안한다.
- `beforeunload`는 current document가 persisted snapshot과 다를 때만 차단한다.
- localStorage의 current serialized baseline과 이전 document serialization을 비교하고 `storage` event를 감시한다. 다른 탭의 write를 발견하면 autosave를 중단하고 `최근 장면 열기`로 충돌을 확인하도록 안내한다.

### Import와 download safety

- import는 전체 text read, size check, JSON parse와 Zod validation이 모두 성공한 뒤에만 live document를 교체한다.
- malformed/oversized import는 live document와 existing autosave를 그대로 보존한다.
- dirty reset/open/import는 native confirmation을 통과해야 한다.
- import generation token과 pending disabled state로 늦게 완료된 이전 file read가 최신 import를 덮어쓰지 못한다.
- hidden file input은 visible import button으로 활성화하며 `tabIndex=-1`로 invisible tab stop을 만들지 않는다.
- JSON download는 sanitized filename, temporary anchor, deferred object URL cleanup 및 error status를 사용한다.

## 결정과 범위 준수

- history에는 serializable document snapshot만 저장하고 runtime Three resources와 transient editor state는 넣지 않는다.
- localStorage는 primitive-only MVP scene에만 사용하며 binary asset persistence, IndexedDB 및 backend는 추가하지 않았다.
- unknown schema version을 암묵적으로 수용하지 않고 future migration boundary를 명시했다.
- malformed source는 복구 가능성을 위해 파괴적으로 삭제하지 않는다.
- explicit user local save는 autosave와 분리하되 같은 validated codec과 storage key를 사용한다.
- S09 exact-resolution PNG/frame export는 구현하지 않았다.
