## 결정

- 앱은 브라우저 전용 local-first SPA이며 MVP 서버는 없다.
- 제품 문서의 고정 출력은 16:9 `1280×720`·`1920×1080`, 9:16 `1080×1920`, 1:1 `1080×1080`, 2.39:1 `1920×804`다.
- 문서가 소유한 OutputCamera만 출력의 진실의 원천이며 편집 내비게이션 중간 상태는 저장하지 않는다.
- 깨끗한 출력과 참조 출력은 별도 레이어/합성 경로로 검증한다.
- `.hermes`의 로컬 상태는 무시하되 `.hermes/plans/**`의 구현 계획은 버전 관리한다.

## 제한과 열린 결정

- S00은 문서 세션이므로 실제 WebGL, PNG, UI, 저장 동작은 아직 존재하지 않는다.
- 최종 제품명·시각 아이덴티티, 정적 호스팅 대상, 저장소 공개 범위는 미정이며 S00–S11을 막지 않는다.
- Node.js `v25.8.1`, npm `11.11.0`이 현재 설치되어 있으나 지원 Node 범위와 의존성 호환성은 S01에서 lockfile과 README로 고정해야 한다.
