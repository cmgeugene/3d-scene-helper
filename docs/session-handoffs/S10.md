## 완료한 목표

범용 animation/timeline을 만들지 않고, I2V start-frame에 필요한 최소 motion previsualization 계약을 추가했다. 현재 선택된 object가 소유하는 subject motion vector 하나와 scene-level camera motion vector 하나만 유지하며, layer 2의 색상 구분 화살표와 한국어 레이블로 의도를 표시한다.

Subject 방향은 left/right/up/down/forward/back, camera motion은 pan/tilt/dolly/orbit 계열 preset을 제공한다. 강도 0..1은 물리 속도나 시뮬레이션 값이 아니라 설명적 화살표 길이로만 사용한다. Scene notes는 최대 2,000자이며 기존 version 1 scene JSON 안에서 round-trip한다.

Clean PNG는 motion guide를 항상 제외한다. Reference PNG는 transient `guideVisibility.motion`이 활성화된 경우에만 layer 2 motion guide를 포함하며, thirds/center/safe-area composition overlays는 motion visibility와 독립적으로 유지한다.

## 구현한 계약

### State와 ownership

- `subjectMotionGuide`는 현재 `selectedObjectId`가 소유한다. Caller가 다른 `subjectId`를 전달해도 store boundary에서 selected object ID로 정규화한다.
- Subject guide는 document 전체에서 하나만 존재하며, 다른 selected object에 preset을 적용하면 기존 guide를 교체한다.
- Guide를 소유한 object를 삭제하면 subject guide도 함께 제거한다.
- `cameraMotionGuide`는 scene-level optional field이며 한 번에 하나만 존재한다.
- Subject 또는 camera guide를 생성하면 transient `guideVisibility.motion`을 자동 활성화한다.
- Toolbar의 `모션 가이드` checkbox와 `모든 가이드 숨기기`가 preview 및 reference export visibility를 함께 제어한다.
- Direction과 strength 변경은 document history/persistence 경계를 그대로 사용한다.

### Preset과 scene notes

- Subject preset: 왼쪽, 오른쪽, 위쪽, 아래쪽, 앞으로, 뒤로.
- Camera preset: 팬 왼쪽/오른쪽, 틸트 위/아래, 돌리 인/아웃, 오빗 왼쪽/오른쪽.
- Strength slider는 0..1 descriptive magnitude이며 renderer arrow length `0.35 + strength * 0.4`에만 반영한다.
- Scene notes textarea는 `maxlength=2000`, live count 및 store-side slice를 제공한다.
- Scene notes와 optional motion metadata는 기존 `version: 1` document에 유지하며 두 번째 document type이나 schema bump를 만들지 않았다.
- Zero-length direction은 schema에서 거부하고 renderer boundary에서도 방어적으로 skip한다.

### Layer-2 renderer와 lifecycle

- Subject guide는 cyan `#24d4ff`, camera guide는 orange `#ffb347`이다.
- Arrow와 label sprite 전체를 `RENDER_LAYERS.reference`(layer 2)에 배치하고 raycast를 비활성화한다.
- Label은 `ArrowHelper` local `+Y` tip 바깥에 배치해 direction transform을 정확히 한 번만 적용한다. 이로써 이전 world/local 이중 회전 결함을 제거했다.
- Opaque dark label background, white text, colored border 및 compact sprite scale로 실제 PNG 가독성을 확보했다.
- Canvas, `CanvasTexture`, `SpriteMaterial`, `ArrowHelper`는 render/useMemo 중이 아니라 committed `useLayoutEffect`에서만 생성·attach한다.
- Cleanup은 생성한 exact helper를 group에서 제거하고 label texture/material 및 ArrowHelper geometry/material을 dispose한다. StrictMode 또는 abandoned render에서 render-time GPU allocation을 남기지 않는다.
- E2E diagnostics는 development/e2e에서만 actual label/origin/tip NDC와 layer를 공개한다. Production build guard에 `motionGuides` marker를 추가했다.

### Export policy

- Clean: layer 0만, motion 및 composition overlays 없음.
- Reference + motion enabled: layer 0+2, active composition overlays.
- Reference + motion disabled: layer 0만 사용하되 active composition overlays는 계속 포함한다.
- Layer 1 editor helpers는 모든 export mode에서 제외한다.
- Playwright가 baseline clean, guided clean, hidden reference 및 visible reference PNG를 실제 download/decode한다.
- Guided clean은 baseline clean과 pixel-identical하다.
- Motion visibility를 끈 reference도 composition flag가 없을 때 baseline clean과 pixel-identical하다.
- Motion visibility를 켠 reference는 cyan/orange arrow, dark label background 및 white label text pixel을 실제로 포함한다.
