output frame은 viewport 안에 16:9, 9:16, 1:1, 2.39:1 결과를 contain하는 DOM rectangle이다. Three `PerspectiveCamera`의 aspect는 viewport가 아니라 document output aspect를 사용한다. `filmGauge=36`에서 `setFocalLength()`로 18/24/35/50/85mm 렌즈를 적용한다.

## 구현한 계약

### OutputCamera, viewport와 commit 경계

- document의 `outputCamera`는 position, target, focal length, roll의 JSON-safe 숫자만 저장한다.
- 실제 R3F `PerspectiveCamera`는 output camera document 값을 runtime에 mirror한다.
- camera aspect는 viewport resize와 독립된 document output aspect다.
- explicit lens, shot, frame-selected, look-at-selected와 OrbitControls pointer-end만 document camera commit boundary다.
- OrbitControls pointer move 중에는 transient `navigation`과 actual runtime camera만 변하며 document camera를 쓰지 않는다.
- pointer-end에서 navigation과 output camera를 한 번 commit한다.
- TransformControls drag 중 OrbitControls exclusion과 output camera 불변 계약을 보존한다.

### Letterbox와 lens projection

- `computeLetterbox(viewportWidth, viewportHeight, outputAspect)`는 pure contain rectangle을 반환한다.
- 1280×720에서 16:9는 전체 frame, 9:16과 1:1은 pillarbox, 2.39:1은 letterbox를 만든다.
- Canvas는 contain rectangle 안에서만 렌더링되어 stretch하지 않는다.
- `PerspectiveCamera.filmGauge=36` 후 `setFocalLength(18|24|35|50|85)`를 호출한다.
- output resize는 crop projection, aspect, focal length 또는 document camera 값을 변경하지 않는다.

### Bounds 기반 framing과 shot semantics

- bounds가 있으면 실제 transformed scene-object AABB를 사용하고, 없으면 0.5×1.7×0.3m reference subject를 사용한다.
- eye-level medium, close-up, Dutch angle은 bounds에 비례한 1.6m/1.7m eye-level target을 사용한다.
- full-body는 bounds center를 target으로 하고 전체 subject를 frame 90% 안에 contain한다.
- low/high angle은 bounds-relative visible region과 elevation을 사용한다.
- frame distance는 camera right/up/depth basis에서 8개 bounds corner를 검사한다.
- current azimuth/elevation과 roll을 보존하는 frame-selected에서도 모든 corner가 requested occupancy 안에 들어온다.
- frame-selected는 position과 target을 explicit commit하고 look-at-selected는 position을 보존한 채 target만 commit한다.
- selection이 없으면 document camera를 보존하고 status feedback을 제공한다.

### Status 및 editor-only helper

- camera feedback은 selection/mode/aspect summary와 함께 status bar에 표시되어 live context를 숨기지 않는다.
- selection, transform mode 또는 output aspect를 변경하면 이전 camera feedback을 지운다.
- facing helper는 selected runtime root의 local `-Z` forward를 표시하고 editor render layer 1만 사용한다.
- helper와 모든 descendant raycast를 비활성화해 selection/gizmo pointer interaction을 막지 않는다.
- selection cleanup에서 root로부터 detach하고 `ArrowHelper.dispose()`를 호출한다.
- facing helper 및 runtime diagnostics는 document/store에 Three instance를 저장하지 않는다.

### Composition guides

- thirds는 1/3·2/3 vertical/horizontal DOM line 네 개다.
- center는 horizontal/vertical crosshair 두 개다.
- action-safe는 output frame 각 변에서 5% inset이다.
- title-safe는 output frame 각 변에서 10% inset이다.
- 개별 visibility toggle과 모든 가이드 숨기기를 제공한다.
- overlay는 `pointer-events: none`이며 output/document scene에 포함되지 않는다.

### E2E diagnostics 격리

- actual runtime camera position/target/aspect/film gauge/focal length/roll, navigation state, facing helper 및 transform diagnostic을 DEV/Vite `e2e` mode에서만 plain-data canvas attribute로 게시한다.
- Playwright는 Zustand state만 보지 않고 actual Three runtime camera와 DOM frame geometry를 함께 검사한다.
- 일반 production build는 `assert-production-bridge-absent.mjs`로 camera/facing/transform/orbit diagnostics가 bundle에 없는지 강제한다.
