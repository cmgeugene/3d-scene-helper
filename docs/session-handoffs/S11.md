## 구현 및 검증 계약

### Complete golden path

Actual Chromium에서 starter floor/mannequin과 neutral `50mm` camera/lighting을 확인하고 cube 추가·transform, `9:16`, `35mm`, full-body camera preset, sunset lighting, composition/motion guide, local save/reload 및 clean `1080×1920` PNG download를 하나의 E2E로 검증한다. 다운로드한 PNG를 decode해 정확한 dimensions를 확인하며 console error와 page error가 모두 0인지 검사한다.

### Persistence 및 export hardening

- Malformed import는 live document와 직전 valid autosave를 byte-for-byte 보존한다.
- Static saved scene의 `1280×720` export를 browser resize 전후 decode하고 mismatch ratio `≤0.001`을 요구한다.
- Clean/reference export는 별도 pixel path를 사용하며 layer 1 editor helper는 둘 다 제외한다.
- WebGL context가 손실되면 열린 export dialog를 닫고 PNG export를 비활성화한다. JSON export와 serialized scene은 유지된다.

### Keyboard 및 accessibility

- Tab/Enter만으로 asset 추가, outliner 선택, inspector numeric commit, export dialog open/cancel을 수행한다.
- Input, textarea 및 contenteditable focus에서는 transform/delete shortcut이 no-op이다.
- 모든 visible button/input/select/textarea의 accessible name을 감사한다.
- 대표 text/background contrast ratio `≥4.5`, `3px solid` visible focus, modal focus trap/return, `aria-live="polite"` status를 실제 browser에서 확인한다.
- 누락됐던 textarea focus style만 기존 공통 form-control selector에 추가했다.

### Render/WebGL resilience

- `SceneErrorBoundary`가 viewport render failure를 격리한다.
- Boundary failure는 shell의 typed `render-error` 상태로 전파되어 WebGL status를 `fallback`으로 바꾸고 PNG export를 비활성화한다.
- `webglcontextlost` listener는 default context-loss 처리를 막고 typed `context-loss` 상태와 복구 안내를 표시한다.
- 두 failure path 모두 current serialized scene, outliner/inspector, local persistence와 JSON export를 보존한다.
- Context listener는 effect cleanup에서 exact canvas listener를 제거한다.
