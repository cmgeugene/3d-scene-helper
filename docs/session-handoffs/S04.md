## 완료한 목표

S03의 editor shell 중앙 placeholder를 실제 React Three Fiber `Canvas`로 교체했다. 직렬화 가능한 `SceneDocument`가 canonical state이고, runtime camera·controls·mesh·material·helpers는 document로부터 한 방향으로 파생된다. Three.js instance는 Zustand 또는 `SceneDocument`에 저장하지 않는다.

viewport는 document background, real floor, bounded shadow lighting, layer 1 grid/axes, layer 0 scene objects를 렌더한다. document `OutputCamera`를 runtime camera에 복사하고 orbit/pan 중에는 transient navigation만 갱신한 뒤 pointer end에서만 camera document를 commit한다.

AssetPanel에서 cube, sphere, cylinder, plane, primitive-only mannequin을 meter 단위 deterministic slot에 추가한다. mesh/outliner 선택, empty-space selection clear, mannequin child raycast의 root ID resolution, visibility/color 반영, material을 변경하지 않는 layer 1 selection helper를 제공한다.

S05 이후 transform gizmo, numeric commit, shortcuts, camera/lighting controls, persistence/history/export는 구현하지 않았다.

## 구현한 계약

### Scene document → Three.js runtime

- `SceneObject` plain data의 kind, dimensions, transform, color, visibility를 runtime geometry/group/material props로 매핑한다.
- runtime root name은 `scene-object:<id>`, display name은 document object name을 사용한다.
- object root click handler가 child mesh event를 받아 document root ID를 선택한다.
- selected object에는 별도 wireframe `meshBasicMaterial` helper를 만들고 layer 1로 고정한다. scene material은 selection 때문에 변경하지 않는다.
- `sceneObjectModel.ts`의 pure mapping/bounds/placement 함수만 Vitest unit 대상으로 둔다.

### Canvas, floor, lighting, helpers

- R3F `Canvas`, `SRGBColorSpace`, `PCFShadowMap`, neutral document background를 사용한다.
- document floor는 10m × 10m × 0.02m real box mesh이며 receive shadow를 활성화한다.
- key light shadow camera를 ±6m로 제한하고 map size는 `MAX_SHADOW_MAP_SIZE` 이하로 clamp한다.
- scene content는 layer 0, 20m grid와 origin axes 및 selection helper는 layer 1이다.
- grid/axes와 selection helper는 raycast 대상에서 제외한다.
- WebGL unavailable 또는 unit-test canvas-disabled 경로에서는 lazy viewport module을 불러오지 않고 기존 fallback을 유지한다.

### OutputCamera와 editor navigation

- document position, target, focal length, roll을 runtime `PerspectiveCamera`에 복사한다.
- runtime camera는 editor layer 1을 함께 표시한다.
- `OrbitControls`는 zoom을 끄고 orbit/pan을 제공한다.
- control start/change 중에는 `navigation.position/target/isInteracting`만 갱신하며 document camera는 유지한다.
- control end에서 camera가 실제로 바뀐 경우에만 기존 `commitCamera()`를 한 번 호출한다.
- OrbitControls가 orientation을 다시 계산한 뒤에도 document roll을 재적용한다.

### Assets와 mannequin

- AssetPanel에서 cube, sphere, cylinder, plane, mannequin만 활성화했다.
- 첫 배치 slot은 starter camera framing 안쪽의 meter coordinates를 순서대로 선택하고, 이를 모두 사용한 뒤에는 음의 Z 방향으로 확장되는 deterministic meter grid를 사용해 기존 위치를 재사용하지 않는다.
- mannequin은 외부 model/rig/animation 없이 sphere, box, cylinder만 사용한다.
- mannequin local geometry는 bottom `-0.85m`, top `+0.85m`로 정확히 1.7m이고 dimensions로 비례 scaling한다.
- primitive와 mannequin의 cast/receive shadow, color, visibility를 document data에서 직접 반영한다.
