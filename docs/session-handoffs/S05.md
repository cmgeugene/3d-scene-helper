## 완료한 목표

선택한 canonical scene object에 대응하는 R3F root `Object3D`에 Drei `TransformControls`를 연결하고 translate, rotate, scale workflow를 구현했다. grouped mannequin의 child mesh를 클릭해도 gizmo는 `scene-object:<id>` root에만 attach한다.

transform drag 시작 시 store의 `beginTransform()`을 호출한다. drag 중에는 runtime `Object3D`만 변경하고 document에는 쓰지 않으며, drag 종료 시 최종 plain-number transform을 `commitTransform()`으로 정확히 한 번 반영한다. gizmo drag 중에는 OrbitControls를 비활성화하고 종료·취소 시 복구한다.

Inspector는 position, degree rotation, strictly-positive scale을 local draft로 편집하고 blur 또는 Enter에서만 commit한다. finite가 아닌 값과 0 이하 scale은 거부한다. 최소 color/visibility 및 duplicate/delete actions를 제공한다. W/E/R, Delete/Backspace, Cmd/Ctrl+D, Escape shortcut을 추가하고 editable target에서는 scene shortcut을 무시한다.

## 구현한 계약

### TransformControls와 runtime/document 경계

- `SceneDocument`와 Zustand에는 JSON-safe 숫자 transform만 저장한다. Three.js instance는 R3F runtime 내부에만 둔다.
- `SceneObject`가 `scene-object:<id>` root를 등록하고 `SelectionTransformControls`는 selected document object와 ID가 일치하는 root에만 attach한다.
- transform gizmo와 picker는 editor layer를 사용하며 scene material/document appearance를 변경하지 않는다.
- drag 시작 시 runtime transform의 plain-data snapshot을 component-local ref에 보존하고 `beginTransform()`을 호출한다.
- drag 중 `Object3D`만 변형하고 canonical document와 Inspector 값은 유지한다.
- pointer-up에서 runtime position/degree rotation/scale을 읽어 `commitTransform()`을 한 번 호출한다.
- invalid final transform은 runtime을 초기 transform으로 복구하고 transaction을 취소한다.
- Escape, selection change, unmount 또는 transaction mismatch에서도 local snapshot으로 runtime을 먼저 복원하고 OrbitControls를 다시 활성화한다.
- active gizmo drag 전·중·후 output camera의 document/runtime 값이 변하지 않음을 실제 Canvas E2E에서 확인한다.

### Inspector와 object actions

- position, rotation(degrees), scale 축별 input은 selected object transform을 초기 local draft로 사용한다.
- typing 중에는 document를 변경하지 않고 blur/Enter에서만 전체 transform을 commit한다.
- 빈 값, NaN, Infinity 및 scale `<= 0`은 commit하지 않으며 canonical 값으로 draft를 복구한다.
- object color와 visibility를 직접 수정하는 최소 controls만 제공하고 material editor는 추가하지 않았다.
- Toolbar와 Inspector 양쪽에 duplicate/delete actions를 제공한다.

### Keyboard actions

- W/E/R은 translate/rotate/scale mode를 선택한다.
- Delete와 Backspace는 selected object를 삭제한다.
- Cmd/Ctrl+D는 selected object를 복제한다.
- Escape는 active transform을 취소하고 selection을 지운다.
- Meta/Ctrl 조합은 W/E/R mode shortcut으로 처리하지 않는다.
- `input`, `textarea`, `select`, contenteditable 또는 그 descendant가 target이면 scene shortcut을 무시한다.

### E2E diagnostics 격리

- actual Three runtime transform, gizmo origin/axis, dragging state 및 OrbitControls enabled state를 DEV/Vite `e2e` mode에서만 plain-data canvas attributes로 게시한다.
- Playwright는 `canvas[data-engine]`에서 실제 pointer drag를 수행한다.
- 일반 production build는 `assert-production-bridge-absent.mjs`로 store bridge와 transform/orbit diagnostics가 bundle에 포함되지 않았음을 강제한다.

## 1280×720 실제 Chromium 검증

Playwright project의 정확한 `1280×720` viewport에서 actual WebGL canvas와 pointer/keyboard events를 사용했다.

- starter mannequin child mesh를 canvas 중앙에서 click한 뒤 root `scene-object:starter-mannequin`에 gizmo가 attach됨.
- cube와 grouped mannequin 각각 실제 translate, scale, Z rotation drag가 runtime과 Inspector/document에 동기화됨.
- drag 중 canonical document transform은 유지되고 runtime transform만 변하며, pointer-up 뒤 document transform change가 정확히 1회 발생함.

- Escape는 변형 중 runtime을 움직인 뒤 selection을 지우고, 재선택 후 runtime/document transform 모두 drag 전 값으로 복구됨.
- Inspector position/degree rotation/scale, color, visibility, duplicate/delete UI가 실제 브라우저에서 동작함.
- W/E/R, Escape, Delete/Backspace, Cmd/Ctrl+D가 동작하고 input/textarea/select/contenteditable focus 중에는 무시됨.
- smoke E2E가 1280×720 page overflow와 최소 viewport contract를 함께 통과함.
